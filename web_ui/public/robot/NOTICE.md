# DG5F-S model assets

The URDF and Collada mesh files in this directory are browser-served copies of
`src/vendor/dg5f_s_description`.

- Model: TESOLLO DG5F-S left hand
- Source package: `dg5f_s_description` version 0.0.1
- Declared license: BSD-3-Clause
- Runtime model: `dg5fs_left.urdf` (20 revolute joints, without mount)

The source URDF copyright and license header is preserved in the copied file.
